# Local Web Fonts

Google Sans is used for headings and controls. Noto Sans is used for prose.
Both files are the unmodified Latin variable WOFF2 distributions, with
weights from 400 to 700, provided by Google Fonts.

Google Sans:
https://fonts.gstatic.com/s/googlesans/v76/4UasrENHsxJlGDuGo1OIlJfC6l_24rlCK1Yo_Iqcsih3SAyH6cAwhX9RPjIUvQ.woff2

Noto Sans:
https://fonts.gstatic.com/s/notosans/v42/o-0bIpQlx3QUlC5A4PNB6Ryti20_6n1iPHjc5a7duw.woff2

The SIL Open Font License notices are included as GoogleSans-OFL.txt and
NotoSans-OFL.txt. No remote font service is contacted by the project page.
